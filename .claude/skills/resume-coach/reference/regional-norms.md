# Regional norms

Default is **United States**: US Letter paper, no photo, no birth date, no marital status,
city + state only, 1-2 pages. Ask where the jobs are during setup. Write the answer into
`my-career/profile.md` (`Job market:` and `Paper size:`).

| Market | Paper | Photo | Length | Notes |
|---|---|---|---|---|
| United States | Letter | Never | 1-2 pages | "Resume". No personal details. Cover letter optional but helps. |
| Canada | Letter | Never | 1-2 pages | Same as US. |
| United Kingdom / Ireland | A4 | Never | 2 pages | Called a "CV". Personal statement at top is normal. |
| Sweden / Nordics | A4 | No | 1-2 pages | Cover letter (personligt brev) expected even if optional. Understated, team-oriented tone; avoid hero language ("exceptional", "I own"). State language level (e.g. Swedish A2) and a concrete relocation plan if moving. If a visa is needed, say commitment is firm and sponsorship makes it possible. |
| Germany / Austria / Switzerland | A4 | Optional, declining | 2 pages | Very structured, complete dates, no gaps unexplained. |
| Netherlands | A4 | Optional | 1-2 pages | Direct, concise tone. |
| France | A4 | Optional | 1 page early career | |
| Australia / New Zealand | A4 | Never | 2-3 pages | Referees section common. |
| India | A4 | Sometimes | 1-2 pages | |

When unsure, follow the US/UK convention for that paper size and ask the person.
Work authorization / sponsorship: never answer on the person's behalf. Ask, record the
answer in `profile.md`, and state it plainly where forms ask.
